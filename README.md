# LLM Engineering

Projects and exercises from my LLM Engineering learning journey.

## Tech Stack

- Python
- OpenAI API
- Hugging Face
- Jupyter
- uv

## Setup

Clone the repository

```bash
git clone <repo-url>
cd LLM-Engineering
```

Install dependencies

```bash
uv sync
```

Create `.env`

```env
OPENAI_API_KEY=your_key
HF_TOKEN=your_token
```

Run

```bash
python main.py
```
