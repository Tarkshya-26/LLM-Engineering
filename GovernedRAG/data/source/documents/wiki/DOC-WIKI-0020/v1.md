# Deployment and rollback runbook

Applies to all production systems.

## Steps
- Confirm the change has an approved review.
- Deploy to staging and run the smoke tests.
- Promote gradually and watch error rates and latency.
- Roll back immediately if error rates rise.
- Record the release in the change log.

## Contacts
- Engineering on-call through the paging system.
- Security for any suspected data exposure.
