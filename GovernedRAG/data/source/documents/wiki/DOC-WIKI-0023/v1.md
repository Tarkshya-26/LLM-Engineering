# Healthllm phi handling procedures

Applies to Healthllm.

## Steps
- Access protected health information only for an assigned ticket.
- Never export member data to personal devices.
- Use the masked support view whenever possible.
- Report any suspected exposure to Security immediately.

## Contacts
- Engineering on-call through the paging system.
- Security for any suspected data exposure.
